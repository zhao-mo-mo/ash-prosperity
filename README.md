# 《灰烬盛世》 - 赵墨 著

这是一部关于真相、虚假与幸存的长篇小说。

在这个世界上，人还在动，还在衣食住行，但其实有些东西已经彻底改变了。如果你定睛一看，你会发现高楼是纸糊的，食物是香灰，连身边的人都是由竹篾和纸浆撑起的皮囊。

但最恐怖的不是发现真相，而是即便你知道了一切，你依然得戴上名为“标准”的滤镜，修补好身上的裂痕，继续在这个巨大的灵堂里演完你的一生。
